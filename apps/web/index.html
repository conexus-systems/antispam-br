AntiSpam BR — Portal Comunitário

Consultar reputação de um número

Digite o número com DDD (ex.: 11 99999-9999). O portal calcula o hash no seu navegador — o número nunca é enviado em texto claro.

🔒 Consulta por hash SHA-256 (E.164). Nenhum dado pessoal é enviado; a resposta é sempre agregada.

Denunciar um número

Sua denúncia é anônima: o servidor recebe apenas o hash do número e um hash rotativo do seu navegador. Uma denúncia isolada nunca bloqueia um número sozinha.

Contestar classificação (falso positivo)

Número seu ou de uma empresa legítima sendo apontado como spam? Conteste — contestações reduz o score de verdade.

Campanhas de golpe ativas (48h)

Números com rajada de denúncias (≥ 5 em 48 horas). Dados agregados — nenhum denunciante é exposto.

Datasets públicos

Snapshots versionados e assinados (Ed25519). O app recusa qualquer dataset sem assinatura válida ou com hash divergente.

Conteúdo: apenas dados agregados e anonimizados (CC0-1.0). Não contém nomes, endereços ou qualquer dado pessoal.

Documentação da API (v1)

Endpoints públicos. Autenticação por limites de taxa (sem conta necessária para consulta).

GET  /v1/numbers/{sha256}/reputation   → { score, label, total_reports, distinct_reporters }
POST /v1/reports                       → { number_hash, category, confidence, source, reporter_hash }
POST /v1/reports/{id}/vote             → { vote: "confirm" | "contest" }
POST /v1/numbers/{sha256}/legitimate   → contestação de falso positivo
GET  /v1/datasets/manifest             → manifest assinado (Ed25519)
GET  /v1/datasets/{version}            → metadados da versão
GET  /v1/campaigns                     → rajadas ativas (agregado)

A API rejeita: timestamps futuros (>5 min), denúncias >7 dias, duplicatas por minuto, payloads >16 KB, categorias inválidas. Números em texto claro são sempre rejeitados.
