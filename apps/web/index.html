AntiSpam BR — Portal Comunitário

Consultar reputação de um número

Digite o número com DDD (ex.: 11 99999-9999). Por padrão o navegador calcula o SHA-256 do número e envia ao servidor só os 5 primeiros caracteres do hash; a comparação final acontece aqui. O servidor não fica sabendo qual número você consultou.

"Ver detalhes" envia o número ao servidor para mostrar também números ainda não publicados e os fatores do score. O servidor não grava consultas.

Denunciar um número

Sem conta e sem e-mail: o navegador resolve uma pequena prova de trabalho e recebe um identificador pseudônimo. Uma denúncia isolada nunca bloqueia um número; é preciso que vários denunciantes independentes concordem por pelo menos 48 horas.

Contestar (falso positivo)

Número seu ou de uma empresa legítima marcado como spam? A contestação vai para a moderação; vinda de dispositivo com histórico confiável, suspende a publicação até a decisão.

Campanhas ativas

Blocos de numeração com 3 ou mais números suspeitos nos últimos 14 dias. Os 4 últimos dígitos ficam mascarados.

Categorias e faixas de score

O score (0–100) cresce com denunciantes independentes, confiáveis e recentes, e cai com contestações e com o tempo (meia-vida de 30 dias).

Datasets públicos

Versões assinadas (Ed25519) com deltas. Os apps recusam dataset com assinatura inválida, expirado ou mais antigo que o instalado.

API v1

GET  /v1/devices/challenge                 → desafio de prova de trabalho
POST /v1/devices                           { challenge, solution } → { device_token }
GET  /v1/numbers/{número}/reputation       → score, faixa, fatores (sem dados de denunciantes)
GET  /v1/reputation/hash-prefix/{5 hex}    → números publicados cujo SHA-256(E.164) começa assim
POST /v1/reports                           Device token · { number, category, nonce, timestamp, comment? }
POST /v1/reports/{id}/vote                 Device token · { vote: confirm | dispute, nonce, timestamp }
POST /v1/numbers/{número}/legitimate       Device token · { nonce, timestamp, comment? }
GET  /v1/campaigns                         → blocos com campanha ativa (mascarados)
GET  /v1/datasets/manifest(.sig)           → manifest assinado mais recente
GET  /v1/datasets/{versão}                 → arquivos da versão

Limites: 3 ações/min e 20/dia por dispositivo; 200/dia por rede. Emergência e utilidade pública (190, 192, 193…) nunca recebem denúncia.
